## 关键坑（已归档知识）

1. **dotnet build 必须 `-p:Platform=x64`**：默认平台产物在 bin\Release，x64 旧 dll 导致新能力不生效（catalog 278 vs 282 对不上）。
2. **PowerShell Set-Content 写 .lua 会带 UTF-8 BOM** → 游戏加载 syntax error near 'local'；改文件用字节级写入或专用编辑工具。errors 段上浮功能正是靠这个案例现场立功。
3. **坐标系三段换算**：引擎分辨率空间（get_resolution）≠ cgui 逻辑空间（÷scale）≠ 编辑器视口逻辑空间；capture crop 必须经 lua.game_info 取逻辑宽换算，窗口尺寸变化后坐标失效需重新 find_ui。
4. **真机日志四组括号前缀**：同条收纳必须连 [序号] 一起剥，否则刷屏行收纳失败（0_49 文件实测 1973→2）。
5. **MCP stdio 首行可能带 PowerShell 管道 BOM**：run_stdio 剥 `\u{feff}`。
6. **dbg_register 定义在 stack 声明前**：upvalue 绑定不到局部栈，必须运行期 `M.top_frame()` 解析。
