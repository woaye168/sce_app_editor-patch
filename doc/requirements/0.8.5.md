## 背景（问题是怎么发现的）

### 起因：调试台遮挡下的操作失真（2026-08-30 真机实证）

v0.8.x 审查真机验证暴露：调试台（cgui_bench，90000 层全屏外壳）打开时，下层的
ShopUI/GMUI/HUD **仍在渲染并沉淀 dbg 快照**，AI 经 MCP 能操作玩家完全不可见的界面
（点技能/买礼包）——测试失真，「AI 所见 ≠ 玩家所见」。两个根因：

1. **cgui 全屏外壳遮挡释放逻辑不完整**（体系性缺口，见下文审查清单）；
2. **调试反射无可见性概念**（dbg 快照对所有控件一视同仁，不区分被遮挡与否）。

| P1-7 | 语义缺陷 | 被挂起面板重复 open 重放 on_open 与事件（ShopUI.on_open 会重发 Req_OpenShop） | 副作用重复执行 |
| P1-8 | 语义缺陷 | bench.open 在 debug_ui 开关拒绝（start 不挂载）后仍挂起全部业务 UI | release/漏配置时调 open = 黑屏 |
| P1-9 | 潜伏 | hidden_views 孤儿恢复路径：panel 挂起者持有同带时视图保持隐藏，但 panel 挂起者关闭不回看 hidden_views | 一旦推广 suspend_layers 即变活 bug |
| P2-10 | 一致性 | z 分带头注释「HUD 10000~19999 / 面板 20000+」vs `LAYER.UI = 20000` 自相矛盾 | 分层约定不可信 |
| P2-11 | 一致性 | 千级旧量纲注释大面积残留（debug_hub/cgui_bench/dialog_host/NotifyBar/HudBar/CombatHUD） | 误导后续开发 |
| P2-12 | 越带 | debug_hub `root_z=500`（世界带魔法数字，低于 RMGUI HUD z=999） | 调试入口有被 RMGUI 主界面盖住的风险 |
| P2-13 | 越带 | imgui_bench 手抄 `z_index = 90000` 字面量，未走 Z.BENCH 注册表 | 违反「z 值唯一来源」约定 |
| P2-14 | 语义矛盾 | NotifyBar `root_z = LAYER.NOTIFY = 60000` 高于 SYSTEM 带；order=UI 带会被 bench 挂起——与「toast 保留」论证自相矛盾 | 通知类元素待遇不一致 |
| P2-15 | 越带 | PlayerLife `root_z=150`（HUD 语义用世界带 z） | 遮挡关系依赖巧合 |
| P2-16 | 层冲突 | TeamHUD 面板与 exclusive 商店/背包同层（POPUP+100），注释却称「可共存」 | 开商店即关队伍面板，注释与现实矛盾 |
| P2-17 | 连带 | remember 600 帧回收 vs 挂起：HUD 被隐藏 >10s，瞬态槽位被 sweep | 恢复后滚动位置等瞬态状态丢失 |
| P2-18 | 卫生 | mount.set_hidden 跳过渲染但 perf_view_ms 残留上次值 | 诊断页显示陈旧耗时 |
| P2-19 | 模板 | src_template `Hud.lua` mount 未传 root_z（新项目第一个 HUD 就是错误示范） | 模板错误示范扩散 |
| P2-20 | 结构 | 挂载缺目录模块化约定（无 `ui/<层名>/<模块>` 结构）；挂载时机不统一（模块加载即挂 vs Init 显式调） | 面板层归属靠口头约定，层值散落硬编码 |

**审查结论中明确「不做」的评估（本期维持，理由记录）**：

- **部分遮挡不做逐像素判定**：dbg 的 `D.order` 是 finish 顺序不感知 root_z/z_index，
  非全屏面板压住 HUD 局部时被压控件仍可点。本游戏全屏面板是主流形态，P0/P1 修完后
  「不可见可操作」主路径已闭合；部分遮挡属边缘场景，成本高收益小（子代理评估，采纳）。
- **imgui_bench 本体不迁移到 cgui**：它是引擎层排障台（原始 imgui 通道是其存在意义），
  本期接入挂起体系 + z 注册表即消除旁路；迁移本体是独立大工程，价值低风险高。
- **NotifyBar root_z=60000 / PlayerLife root_z=150 行为保留**：中央警告/死亡黑幕的
  现有遮挡行为是实测调出来的，无真机证据前不改行为，只修正文档表述。
- **remember 回收 vs 挂起（P2-17）**：调试态边缘场景，暂记为已知边界，不在本期做
  槽位冻结机制。

## 验证方式（test_res002 真机）

- 链路：`bgd_sce_tools build` + MCP `stop_debug/start_debug`（秒级迭代），场景脚本一把跑；
- **挂起遮挡**：调试台/全屏商店打开时，find_ui 找不到下层控件（HUD 按钮/对面面板），
  tap 下层控件 actionable 报错，有 `occluded_skipped` 回显，capture 画面无下层渲染；
- **挂起期间新开面板**：bench 打开中开背包 → 立即进入挂起态（不渲染不进快照）；
  bench 关闭 → 背包恢复渲染，商店被 exclusive 关闭不同屏；
- **恢复**：关闭全屏外壳后下层 UI 恢复渲染且可操作，同层次序/back 导航不失真；
- **exclusive 互斥**：挂起/恢复往返后同层 exclusive 仍互斥；
- **目录推导**：迁移后全面板正常注册（无层不一致告警；层不一致时 warn 可见）；
- **调试台全页面回归** + **全面板回归**（商店/背包/GM/HUD/技能）：每面 ≥1 次 find
  命中 + ≥1 次操作生效 + ≥1 次断言；
- 两处日志 **errors=0**。
