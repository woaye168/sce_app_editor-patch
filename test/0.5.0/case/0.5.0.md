## P0 端口启动（本轮 Bug 修复验证）

| # | 用例 | 预期 |
| --- | --- | --- |
| P0-1 | 配置端口 39177（落在系统保留段 39173-39272 内）启动编辑器 | 日志出现「落在系统保留端口段内…自动向后避让」WARN；无「端口被占用」ERROR；端口文件写入实际端口；服务可达 |
| P0-2 | 改配置端口到保留段外（如 41801）启动 | 直接绑定 41801 成功，无避让 WARN |
| P0-3 | 用一个 TCP 监听进程占住配置端口后启动 | 日志「绑定失败…尝试向后避让」WARN，服务避让到下一可用端口，端口文件一致 |

## M4 datacore（数编读写）

| # | 用例 | 预期 |
| --- | --- | --- |
| M4-1 | invoke datacore.list_entries | 返回 entry 列表及顶层字段 |
| M4-2 | invoke datacore.read（map_config 某路径） | 返回 JSON 树，中文不转义 |
| M4-3 | invoke datacore.write 写测试字段后 read 回读 | 值一致；auto_commit 默认行为符合 R2 实证结论 |
| M4-4 | invoke datacore.batch_write 多字段一次提交 | 全部生效；界面无异常刷新 |
| M4-5 | batch_write 中间一项非法 | 遇错即断，返回 failed_index/applied_count/committed:false |
| M4-6 | 【人工·R2 实证】write(auto_commit=true) 后编辑器 Ctrl+Z | 记录可否撤销，结论回填 doc/research/mcp-capability-survey.md §6.2；不可撤销则 auto_commit 默认改 false + datacore 写类升 danger |
