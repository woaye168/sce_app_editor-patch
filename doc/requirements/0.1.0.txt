请结合   bgd_sce_tools 、 bgd_sce_framework 、bgd_sce_plugins 开发 sce_app_editor-patch 应用。 关于应用开发可以参考 sce_app_visual-injector 。

----
sce_app_editor-patch ，实现的功能是，给星火编辑器打补丁，实现星火编辑器自身的功能扩展。

当前需要做的功能：
需求1、初步完善补丁机制的架构
需求2、解除编辑器的使用限制
需求3、有一个初步的补丁模块，可以勾选应用。

具体实现思路参考：
第1步：通过 bgd_sce_tools 的编译版本内的 「应用 - 应用市场」安装 「sce_app_editor-patch  中文名：编辑器补丁」
第2步：打开「编辑器补丁」应用，应用中心的已有的原生机制会自动传入项目
第3步：从路径「 项目路径/project/map_settings.json」文件能获取到 api_version 版本号。
第4步：从路径「 项目路径/script/tsconfig.json」文件获取到 typeRoots 任意一条，类似「"D:/sce_online/Update/editor-pd.spark.xd.com/Res/_m/maps/global_default/53/global_default/script/"」 
第5步：从「第4步」中，我们提取「D:/sce_online/Update/editor-pd.spark.xd.com」路径。
第6步：用「第5步」的路径，然后加上「api_pak_version.json」得到路径「D:/sce_online/Update/editor-pd.spark.xd.com/api_pak_version.json」
第7步：用「第6步」JSON文件，结合「第3步」得到的项目编辑器版本号，我们可以拿到项目所用编辑器版本的所有包。在这些包里，我们主要是拿到「script 包，也可以称为 common包」，类似  "13":{ "script":199}。
第8步：拿「script」包的版本号之后，我们就可以用「第5步」的路径进行拼接，找到「script」包在本电脑的真实文件路径，比如： 「D:\sce_online\update\editor-pd.spark.xd.com\res\_m\script\199\script\common」
第9步：「需求2 解除编辑器的使用限制」，实际就是还原「common」包里的「isolation.lua」文件。并且把里面置为nil禁用的函数解除禁止。（注意要备份没还原没修改的原文件，以后类似但凡补丁涉及到修改星火编辑器源码的也都要备份，所以本应用有完备的备份机制和合理的自持的可扩展的备份文件目录）
第10步：「需求1 初步完善补丁机制的架构」，其实也可以在「isolation.lua」补丁来解决。比如在「第8步」得到的「common」目录下，创建一个「本仓库」同名的目录「sce_app_editor-patch」，然后把这个目录包的入口文件注入到「isolation.lua」。
第11步：当完成「需求1」和「需求2」，实际上也就可以完成了。无非就是勾选补丁模块「开启」或者「关闭」。

界面需求描述：
1、标签1「内核」功能：「应用补丁」和「还原补丁」，还原补丁就是把星火编辑器的源码还原（用备份还原）
2、标签2「补丁」功能：展示所有已经的补丁列表，可以开启和关闭
3、标签3「帮助」功能：介绍本应用的作用，特别要告知，应用补丁后要重启星火编辑器才能生效。

//使用方法:安装nodejs后，在命令行中输入 node index.js <输入路径> <输出路径>? 输出路径可选 在当前目录中创建 xor_output 文件夹

const fs = require('fs');  
const path = require('path');  

// XOR 加密/解密函数  
function xorEncryptDecrypt(data, keyBytes) {  
    let hex = Buffer.from(data).toString('hex'); 
    let keyLength = 0;  // 密钥循环长度
    let topNum = 4; // 头部标识长度
    let hexSumNew = ''; // 转换后 16进制 字符串

    for (let index = topNum * 2; index < hex.length; index += 2) {
        let hexNum = parseInt(hex.substr(index, 2), 16); // 优化字符串到整数的转换
        hexSumNew += ('00' + (hexNum ^ keyBytes[keyLength % keyBytes.length]).toString(16)).slice(-2); // 简化逻辑，使用模运算符循环密钥
        keyLength++;
    }
    return Buffer.from(hexSumNew, 'hex');  
}  
  
// 处理单个文件  
function processFile(filePath, outputDir, keyBytes) {  
    const data = fs.readFileSync(filePath);  
    const encryptedDecryptedData = xorEncryptDecrypt(data, keyBytes);  
    const outputFilePath = path.join(outputDir, path.basename(filePath));  
    fs.writeFileSync(outputFilePath, encryptedDecryptedData);  
    console.log(`已处理文件写入 ${outputFilePath}`);  
}  
  
// 递归处理文件夹  
function processDirectory(dirPath, outputDir, keyBytes) {  
    const files = fs.readdirSync(dirPath, { withFileTypes: true });  
    files.forEach(file => {  
        const filePath = path.join(dirPath, file.name);  
        if (file.isDirectory()) {  
            // 如果是文件夹，则递归处理  
            const outputSubDir = path.join(outputDir, file.name);  
            if (!fs.existsSync(outputSubDir)) {  
                fs.mkdirSync(outputSubDir, { recursive: true });  
            }  
            processDirectory(filePath, outputSubDir, keyBytes);  
        } else {  
            // 如果是文件，则处理文件  
            processFile(filePath, outputDir, keyBytes);  
        }  
    });  
}  
  
// 命令行参数处理  
if (process.argv.length !== 3 && process.argv.length !== 4) { 
    console.log('指令: node index.js <输入路径> <输出路径>?'); 
    process.exit(1);  
}  
  
const [, , inputDirPath, outputDirPathArg] = process.argv;  
  
// 密钥字符串  
const keyBytes = [67, 82, 69, 65, 84, 69, 69, 65, 83, 89] // 密钥  
// 将密钥字符串转换为字节序列  
// const keyBytes = stringToByteArray(keyStr);  
  
// 确定输出路径  
let outputDirPath = outputDirPathArg;  
if (!outputDirPath) {  
    // 如果没有提供输出路径，则使用默认路径  
    outputDirPath = path.join(__dirname, 'xor_output');  
}  
  
// 在处理之前删除输出路径中的所有内容  
if (fs.existsSync(outputDirPath)) {  
    // 删除输出路径中的所有文件和文件夹  
    const files = fs.readdirSync(outputDirPath, { withFileTypes: true });  
    files.forEach(file => {  
        const filePath = path.join(outputDirPath, file.name);  
        if (file.isDirectory()) {  
            // 如果是文件夹，则递归删除  
            fs.rmSync(filePath, { recursive: true });  
        } else {  
            // 如果是文件，则直接删除  
            fs.unlinkSync(filePath);  
        }  
    });  
} else {  
    // 如果输出路径不存在，则创建它  
    fs.mkdirSync(outputDirPath, { recursive: true });  
}  
  
// 处理输入文件夹  
processDirectory(inputDirPath, outputDirPath, keyBytes);
