## E10 追记（2026-08-19）：截图方案真机验证与方案更替

- **初版引擎 snapshot（snapshot_scene_callback）真机否定**：test_res002 截出纯色底——只截 3D 场景渲染、不含游戏 UI 覆盖层，对「验证 UI」核心用途不成立。
- **终版方案真机通过**：lua 桥 `get_game_view_rect`（base.ui viewport 控件 get_screen_rect 逻辑矩形）+ bgd_sce_tools WGC 截显示器按比例裁剪，test_res002 截出完整游戏画面+游戏 UI（血条/技能栏/背包/GM 按钮等全部入镜，无编辑器界面）。
- 排障过程沉淀（已写入 doc/research/publish-and-capture.md R2 证据链）：
  1. 编辑器主区不是 XAML（内容区是 re-parent 的引擎自绘 SDL 窗口），C# 视觉树找不到 SwapChainPanel；
  2. SDL_app 窗口无法直接 WGC（GraphicsCaptureItem 创建失败），必须截显示器再裁剪；
  3. PIE 视口位置经由 base.ui 控件元表 `get_screen_rect()` 暴露，`common.get_resolution()` 给逻辑分辨率；
  4. 编辑器 exe 是启动器——真实编辑器进程是另一个 pid（必须以桥 server_info.pid 为准）。

## 真机实录（E4–E9 关键证据）

- `editor start`：73.5s 拉起并等桥上线，返回 `{pid, port:39273, mcp_url}`——端口自动避让（39177 被占→39273）实证。
- `start_debug`（restart_last_debug）：`debugging:true`，跳过编辑器编译构建。
- 旧版桥调 `lua.capture_game`：干净返回 NOT_FOUND（错误路径符合预期）。
- `stop_debug`：`debugging:false`。
- `editor stop`：server_info 取 pid → `taskkill /T /F` → 进程消失（返回 `{stopped:true, pid}`）。
- `logs`：五类日志源正确返回最新文件 path/size/created/modified/lines，默认零内容。

## 踩坑与修复（本轮新增知识）

1. **make_slots 对已打补丁的编辑器根重跑会双重注入** → slot_inject 增加 strip_slot/strip_unlock 幂等剥离；manifest 哈希必须取「干净官方源」（本轮 199/160/169 用整库备份的原始源重新生成）。
2. **strip_slot 初版全局折叠空行误伤官方源码**（官方文件有连续双空行）→ 只在拼接点折叠。
3. **进程级 env 覆盖（EDITOR_PATCH_BACKUP_DIR）的端到端测试并发互踩**（同 PID 目录名 + env 竞争）→ ENV_LOCK 序列化 + 独立目录名。
4. **MCP 聚合侧桥调用超时必须按操作分级**：start_debug 桥内轮询最长 120s，客户端 10s 会先超时（但编辑器侧实际仍在启动）→ bridge_rpc 增加 timeout_ms 参数（调试 150s / 状态 15s / 握手 5s）。
5. **强杀后 port 文件残留**（/F 不跑 OnProcessExit）→ 在线判定已是「port 文件 + initialize 握手」双重确认，残留文件自然失效，无需额外清理。
