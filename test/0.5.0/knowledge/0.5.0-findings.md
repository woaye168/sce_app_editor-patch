# 0.5.0 自测自修新知识（已验证并落盘 doc/research）

1. **Windows 系统保留端口段**：Hyper-V/WSL/winnat 动态保留整段 TCP 端口（`netsh int ipv4 show excludedportrange tcp`），段内绑定报 ERROR_SHARING_VIOLATION（"另一个程序正在使用此文件"），netstat 无记录、换段内端口无效、每开机变化。已落盘 mcp-integration-guide.md 排错节；McpServer 启动自动探测避让。
2. **编辑器 first-chance 异常陷阱**：注入进程内任何异常（即使被 catch）都会被编辑器记录并可能弹「发生异常」模态，模态期 DispatcherQueue 不泵 → 全部 UI 调用连锁超时。桥内业务错误必须返回错误对象、零异常。
3. **IDataCore 写入三大坑**：写路径相对 Game 对（剥首段 "Game"）；decimal 封送必炸（自实现 DataDouble）；文本字段需 MakeText。数编不允许新建 schema 外字段。SCE list 1 基。
4. **CommitChanges 不可撤销**（R2 实证）：不进 UndoRedoManager 栈 → 写类 danger + 默认不自动提交。
5. **run_lua 逃生舱的妙用**：danger_allow 实时生效（无需重启），可用来驱动编辑器内部 API 做实证（如 UndoRedoManager），是真机验收的瑞士军刀。注意 run_lua 里 SCE 非全局，需 `ImportSCEContext()` 自取。
6. **PowerShell 管道陷阱**：命令字符串中 `\x` 会被传输层按十六进制转义吞掉（`xdeditor` 路径连续踩坑）——含 `\x` 前缀目录名的路径用 Glob/Get-ChildItem 程序化获取；含中文的 .ps1 必须 UTF-8 BOM（Windows PowerShell 5.1 无 BOM 按 GBK 解析直接语法错误）。
