# 0.5.4 需求与方案：MCP 架构解耦 + 真后台游戏截图 + 拍照按钮修复

> 状态：已实现并真机验证（编辑器最小化/遮挡均可截取纯游戏画面+游戏 UI；拍照按钮修复含打开文件夹与倍率）
> 承接：0.5.3（场景一 MCP 链路的初版实现）

## 需求（原始）

1. **架构**：MCP 不应挂在 bgd_sce_tools 主程序上。正确形态：主程序不关心应用功能；应用需要随主程序静默启动时，在主程序配置里设置（且应用单开）。
2. **编辑器 exe 名**配置应在 sce_app_editor-patch 的设置里（防用户改过 exe 名）。
3. **capture_game 重做**：原方案（外部 WGC 截屏）不是真后台（编辑器被遮挡/最小化不可截）且视口裁剪有偏差。实现思路：
   - 扩展 bgd_mcp_bridge.dll 支持对编辑器指定区域视窗完整截屏；
   - 修复 PIE 调试视图的「拍照」按钮（官方引擎快照拍不到 UI），结合后台截屏能力 + 补丁 gameplay_in_editor_view.lua；
   - 补丁后的拍照功能 = MCP 截屏功能；仅调试中可用；支持倍率参数（对应游戏视图左上角的分辨率/倍率选择）。

## 方案与实测结论

### 1. MCP 宿主迁移（应用自持，宿主解耦）

- **sce_app_editor-patch 新增 CLI/stdio 能力**：`mcp`（stdio MCP 聚合服务，恒定 8 工具）/ `editor start|stop` / `logs` / `capture`（代码自 bgd_sce_tools 迁入并定稿）。
- **bgd_sce_tools 移除** editor/mcp 耦合代码；新增通用「随主程序启动」：应用设置 `auto_start_apps`（应用市场页逐应用勾选），宿主 GUI 启动时静默拉起（单开守卫：进程已在运行则跳过；「打开」按钮同样单开）。
- **editor_exe_name** 迁移到「编辑器补丁」设置页（存 `<运行根>/logs/bgd_csharp/config.json`），editor start 即时生效。
- MCP 客户端配置指向应用 exe：`"command": "<宿主>/apps/editor-patch/sce_app_editor-patch.exe", "args": ["mcp"]`。

### 2. 真后台截图（capture_game 终版）

实测排查链（全部真机验证）：
- SDL 内容窗口直接呈现（非重定向表面）：WGC 截出**黑图**、PrintWindow 黑图；
- WinUI 主窗口有重定向表面，WGC 可截完整合成画面（含 re-parent 的 SDL 内容与游戏画面+游戏 UI）；
- WGC 对**隐藏/最小化**窗口创建 GraphicsCaptureItem 失败；对**遮挡**窗口正常（重定向表面仍在）；
- 视口精确矩形有官方 API：PIE 视口是 base.ui 控件树的 viewport 控件，`get_screen_rect()` 给出引擎 UI 逻辑坐标（即分辨率切换所控制的区域），`common.get_resolution()` 给逻辑分辨率；逻辑坐标与帧像素等比、内容区在帧内底对齐（顶部为 WinUI 标题栏）——无估算成分。

终版链路（`src/core/capture.rs`）：
1. lua 桥 `lua.get_game_view_rect` 取视口逻辑矩形；
2. 找编辑器 WinUI 主窗口（排除 bgd_mcp_bridge 同名类窗口；优先可见最大窗口，避开最小化停靠占位）；
3. **真后台关键**：窗口最小化/隐藏时，保存 WINDOWPLACEMENT → `SW_SHOWNOACTIVATE` + 挪到 (-32000,-32000) 屏外离屏显示（用户屏幕无感知、不抢焦点）→ 等首帧（~2.5s）→ 截取 → 还原 placement（回到最小化/隐藏与原位置）；
4. WGC 截窗口 → GPU 裁剪 → 倍率重采样（Lanczos3）→ 快速 PNG（Fast+NoFilter）落盘。

### 3. pie_capture 补丁（拍照按钮修复）

- **slots 覆盖**：`slots/xdeditor/169/ui/gameplay_in_editor_view.lua` 由 `examples/make_pie_slot` 从 pristine 生成（备份目录取官方源），仅替换 `on_game_snapshot_click` 整段（锚点 = 起始行 + 同缩进收尾 end；锚点失败明确报错），manifest 记 `pie_capture_fix` 条目。
- **新 handler**：调本应用 `capture` CLI（os.execute，非阻塞 start /min），倍率取拍照按钮旁的倍率选择（x½~x4），输出沿用官方路径 `D:/sce_online/User/screenShot/editor_screenShot_N.png`，完成后 CLI 用资源管理器选中文件（--open-explorer，替代官方打开文件夹行为，不依赖编辑器 lua 计时器）；模块未启用时回退官方引擎快照并提示。
- **模块职责**（patches/xdeditor/pie_capture）：承载 `_exe_path.lua` 注入（应用启用/刷新时写入本应用 exe 路径），加载时放入全局 `_G.BGD_CAPTURE_EXE`——必须走全局：run_lua/其他包上下文里 require 本包文件会落到 @common 搜索器而失败，只有模块加载时的包上下文能正确解析。模块同时提供该功能的启停开关。

### 4. 已知边界

- 窗口最小化/隐藏时截取会先离屏恢复（多花 ~2.5s 且窗口在原位闪一下——实际在屏外不可见）；可见时单次 ~1s。
- 截图为窗口当前尺寸下的游戏视图分辨率；更高分辨率用 ratio 倍率（重采样放大，非原生渲染放大）。
- pie_capture 对存量用户需手动勾选一次（默认勾选只对首次创建补丁目录生效）；勾选后重启编辑器生效。
