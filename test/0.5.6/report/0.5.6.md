## 踩坑

1. CLI `logs --project-path` 位置参数误吞 flag（source 变成 --project-path）→ 位置参数解析改为剔除 --flag 及值。
2. windows-sys 的 CreateMutexW/CreateEventW 需同时启用 Win32_System_Threading + Win32_Security。
3. 单实例只作用于 GUI 路径——mcp/editor/logs/capture 等 CLI 短进程在分发前就退出，不受互斥体影响（MCP 客户端拉起多个 stdio 实例不受影响）。

## 遗留（用户侧验证项）

- 「关闭自启应用后打不开」的原始场景未在本机复现（本轮 CREATE_NO_WINDOW + 异步 + editor-patch 单实例唤起已覆盖重开链路）；若 0.6.7 升级后仍出现请反馈具体复现步骤。
