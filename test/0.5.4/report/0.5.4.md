## 踩坑与修复

1. **make_pie_slot 锚点匹配初版用 `trim()=="end"`**：handler 内嵌套 if 的 end 被误匹配导致文件结构破坏（编辑器启动报错）→ 改为同缩进精确匹配。
2. **`game_snapshot_index` 未初始化崩溃**：官方依赖 update_game_snapshot_index 先行，部分路径未执行 → handler 加防御（pcall 初始化 + or 0）。
3. **run_lua 上下文无法 require 本包子文件**（落到 @common 搜索器）→ exe 路径改由模块加载时（正确包上下文）写入全局 `_G.BGD_CAPTURE_EXE`。
4. **截图开窗动作不可见化**：初版最小化时 SW_RESTORE 会在用户屏幕弹出窗口 → 终版离屏显示（SHOWNOACTIVATE + (-32000,-32000)）+ WINDOWPLACEMENT 还原。
5. **窗口选择的坑**：最小化时主窗口停靠为 160x28 占位、另有隐藏辅助窗口——按「可见优先 + 面积最大」选窗。
6. **官方「打开文件夹」走 base.wait 计时器在按钮链路不可靠** → 改由 CLI 进程截图后 explorer /select。
